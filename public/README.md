# Public Assets

This directory contains static public assets such as:
- Images
- Icons
- Fonts
- Other static files

## Croydon Council logo (required for header)

Place the official logo file in this folder:

| File | Purpose |
|------|--------|
| **`public/croydon-housing-logo.png`** | Main app header (top left), Neighbourhood Voice wizard intro, and anywhere `/croydon-housing-logo.png` is referenced |

The current **Croydon Housing** banner is designed for a **black** background; the app wraps it in a black rounded bar for readability on light headers. Replace **`public/croydon-housing-logo.png`** with your PNG to update the logo everywhere.
